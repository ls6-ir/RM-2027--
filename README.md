## 参数表

1. 定时器时钟是 72 MHz  
   TIM2 挂 APB1，72MHz → APB1 分频 2 → 36MHz  
   但 APB 分频≠1 时定时器时钟自动 ×2 → 72MHz
2. 让 1 个计数 = 1µs  
   72MHz ÷ (PSC+1) = 1MHz → PSC = 71
3. 让周期 = 20ms（50Hz）  
   1MHz × 20ms = 20000 → ARR = 19999

## 运行现象

串口内容与 OLED 三行一致：目标角度 / CCR / 脉宽。
